## Flutter Recycler Animations 🚀
```
A lightweight, flexible Flutter library that adds beautiful, RecyclerView-style animations
to ListView items — inspired by Android RecyclerView Animators.

Built to be simple, performant, and fully customizable.
```
## ✨ Features
```
🎬 Multiple built-in list item animations

⚡ Staggered animations (index-based delay)

🧩 Works with any widget

🪶 Lightweight & dependency-free

🎛 Custom duration & animation curve

📱 Supports large lists

🧪 Example app included
```
## 📦 Supported Animations
```
Fade

Slide Left / Right / Up / Down

Scale

Fade + Slide

Rotate

Flip (X / Y)

Bounce
```

## 🚀 Installation

Add this to your pubspec.yaml:
```
dependencies:
  flutter_recycler_animations:
    git:
      url: https://github.com/your-username/flutter_recycler_animations.git
```
## 🛠 Usage

import 'package:flutter_recycler_animations/flutter_recycler_animations.dart';
